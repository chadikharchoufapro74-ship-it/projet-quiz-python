# Projet Quiz - PROJ531

Application de création et de gestion de quiz développée en Python dans le cadre du module PROJ531[cite: 4, 5].

## Fonctionnalités principales
- **Gestion des utilisateurs :** Inscription, connexion sécurisée et conservation de l'historique des scores individuels[cite: 5].
- **Espace Administrateur :** Création de quiz personnalisés (directement dans l'application ou par importation de fichiers texte)[cite: 5].
- **Espace Joueur :** Sélection d'un quiz, passation des questions, calcul du score final et affichage des bonnes réponses[cite: 5].

## Installation
1. Cloner le dépôt GitHub sur votre machine.
2. S'assurer d'avoir une version de Python installée.
3. Exécuter le script principal.
